About The Project

This project is an employee management system developed as a web application using ASP.NET Core MVC.

The system is designed to manage employee information and provide a simple and organized interface for working with employee data.

SQL Server is used for storing and managing the application data.

Main Features

  • Employee management
  • Employee information display
  • Database integration
  • ASP.NET Core MVC architecture
  • SQL Server database
  • Responsive interface
